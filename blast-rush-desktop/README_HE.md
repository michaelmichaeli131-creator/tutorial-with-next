# Blast Rush — גרסת מחשב

גרסה עצמאית ל-Windows שפועלת ישירות בדפדפן, ללא Xcode וללא התקנת ספריות.

## הפעלה ב-Windows

1. הורד את התיקייה `blast-rush-desktop` מהענף או מה-Pull Request.
2. חלץ את הקבצים אם הורדת ZIP.
3. לחץ פעמיים על `PLAY_WINDOWS.bat`.
4. המשחק ייפתח ב-Chrome, Edge או בדפדפן ברירת המחדל.

אפשר גם לפתוח ישירות את `index.html`.

## שליטה

- עכבר: לחיצה על ליבות האנרגיה.
- `Space`: הפעלת Overdrive כשהמד מלא.
- `B`: הפעלת Reactor Blast כשהמד מלא.
- `P`: השהיה והמשך.
- `F`: מעבר למסך מלא.

## מה כלול

- גלים וקושי עולה.
- ניקוד, קומבו ופגיעות PERFECT.
- ליבות רגילות, משוריינות, פצצות וליבות ריפוי.
- פיצוצי שרשרת.
- Overdrive ו-Reactor Blast.
- קרב בוס בכל גל רביעי.
- שמירת שיא, גל שיא ומספר ריצות במחשב המקומי.
- אפקטים, חלקיקים ורעידות מסך.

המשחק אינו דורש חיבור לאינטרנט לאחר הורדת הקבצים.
